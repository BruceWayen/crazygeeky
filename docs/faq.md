# 常见问题

**订阅更新失败 / 导入后没有节点？**
先用浏览器打开订阅链接。打不开说明当前网络访问不了 GitHub，请换网络环境后再试。排查文章：[订阅更新失败怎么办](https://crazygeeky.com/troubleshoot/sub-update-failed/)。

**节点显示可用却连不上？**
免费节点可用性会波动。多换几个节点，或在客户端里点“更新订阅”拿最新一轮。排查文章：[节点连不上怎么办](https://crazygeeky.com/troubleshoot/node-cannot-connect/)。

**该用哪个文件？**
Clash 系客户端用 `mihomo.yaml`；其他客户端用 `base64.txt`；只想要某个地区就用 `subs/us.yaml` 这类拆分文件。

**多久更新一次？**
大约每 6 小时。数据见 README 里的统计表，完整统计见 [https://crazygeeky.com/nodes/](https://crazygeeky.com/nodes/)。

**为什么有的地区文件没有？**
该地区存活节点不足 5 个时不单独发布，节点仍在 `all.yaml` 和 `base64.txt` 里。

**这些节点安全吗？**
不保证。请阅读 [SECURITY.md](../SECURITY.md)，不要用于敏感账号。

**想要更稳定的服务？**
可以参考 [机场选购指南](https://crazygeeky.com/airports/)。该页面可能含推广链接，我们可能因推荐获得佣金。

**客户端在哪里下载？**
请到官方发布页，见 [客户端中心](https://crazygeeky.com/clients/)。
