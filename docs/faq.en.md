# FAQ

**Subscription update failed, or no nodes after importing?**
Open the subscription URL in a browser first. If it won't load, your network can't reach GitHub; switch networks and retry. Troubleshooting article (Chinese): [What to do when a subscription fails to update](https://crazygeeky.com/troubleshoot/sub-update-failed/).

**A node shows as available but won't connect?**
Free nodes fluctuate. Try other nodes, or update the subscription in your client to get the latest round. Article (Chinese): [Node won't connect](https://crazygeeky.com/troubleshoot/node-cannot-connect/).

**Which file should I use?**
Use `mihomo.yaml` for Clash-family clients, `base64.txt` for everything else, and split files such as `subs/us.yaml` if you only want one region.

**How often is it updated?**
About every 6 hours. See the stats table in the README, or [https://crazygeeky.com/nodes/](https://crazygeeky.com/nodes/) for the full picture.

**Why is a region file missing?**
When fewer than 5 nodes are alive in a region we don't publish a separate file. Those nodes are still in `all.yaml` and `base64.txt`.

**Are these nodes safe?**
Not guaranteed. Read [SECURITY.md](../SECURITY.md) and never use them for sensitive accounts.

**Where do I download clients?**
From the official release pages; see the [Clients hub](https://crazygeeky.com/clients/).
