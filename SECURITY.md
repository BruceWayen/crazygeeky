# 安全与风险声明 / Security and Risk Notice

## 中文

- 本仓库发布的节点来自网络公开来源，经存活检测和去重，**不保证安全、不保证可用**。
- **请勿使用这些节点登录银行、支付、主要邮箱等敏感账号**；流量可能被节点运营者查看或篡改。
- 检测在海外服务器进行，结果不代表国内网络下的速度。
- 请遵守你所在地的法律法规，使用风险自负。
- 本仓库和网站不托管任何客户端安装包，请只从官方发布页下载客户端。

### 报告安全问题
如果你发现本仓库内容存在安全问题（例如订阅文件里出现恶意链接或异常内容），请通过 [Issues](../../issues/new/choose) 联系，或到 [https://crazygeeky.com](https://crazygeeky.com) 查看联系方式。请不要在公开 Issue 里贴出你的个人密钥或账号信息。

## English

- The nodes published here come from public sources on the internet. They are liveness-checked and de-duplicated, but **safety and availability are not guaranteed**.
- **Do not use them to sign in to banking, payment, primary email or other sensitive accounts.** Node operators may be able to see or tamper with your traffic.
- Checks run on an overseas server and do not reflect speed from mainland China.
- Follow the laws where you live. You use these files at your own risk.
- Neither this repository nor the website hosts client installers. Download clients only from their official release pages.

### Reporting a security problem
If you find anything unsafe in this repository (for example a malicious link or unexpected content in a subscription file), open an [Issue](../../issues/new/choose) or see [https://crazygeeky.com](https://crazygeeky.com). Never paste personal keys or account details in a public issue.
